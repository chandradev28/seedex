# Security policy

## Reporting

Please report vulnerabilities privately through GitHub's security advisory feature for this repository. Do not open a public issue containing an exploit, private tracker URL, magnet identifier, user path, IP address, signing key, or credential.

## Scope

High-priority areas include path traversal in torrent metadata, unintended file deletion, content-URI handling, source attribution spoofing, Android intent injection, foreground-service control, and native dependency supply-chain integrity.

## User privacy

BitTorrent is not anonymous. Seedex does not conceal a device's peer IP and must never claim that it does. Users should treat tracker, peer, filename, and source data as sensitive.
